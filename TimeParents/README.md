# TimeParents (타임페어런츠) v1.9.0

자녀의 올바른 컴퓨터 사용 습관을 기르기 위한 Windows 기반 PC 사용 시간 제한(자녀 보호) 프로그램입니다.

---

## 🚀 주요 기능 (Key Features)

1. **3가지 타이머 모드**:
   - **카운트다운**: 설정한 타이머 시간(시/분)이 지나면 시스템 종료/로그오프/화면잠금.
   - **특정 시간 지정**: 특정 시각(예: 오후 10시 30분)이 되면 시스템 종료/로그오프/화면잠금.
   - **특정 게임 제한**: 지정한 게임 프로세스(예: `RobloxPlayerBeta.exe`)가 켜져 있을 때만 타이머 시간이 실시간 차감되며, 제한 시간 만료 시 시스템 종료/로그오프/화면잠금.

2. **시스템 트레이 (백그라운드 실행)**:
   - 타이머 작동 중 창을 닫거나 최소화하면 트레이 영역으로 자동 숨김 처리되어 백그라운드에서 감지가 지속됩니다.
   - 트레이 아이콘 우클릭 메뉴를 통해 복구, 중지, 종료를 선택할 수 있습니다.

3. **비밀번호를 통한 오작동 및 종료 차단**:
   - 자녀가 프로그램을 임의로 종료하거나 타이머를 강제 중지하는 것을 방지하기 위해 **비밀번호(솔트를 적용한 PBKDF2 해시)** 검증을 거칩니다.
   - 비밀번호는 파일과 레지스트리에 함께 저장되어, `password.json`을 지워도 자동 복구되고 사용 기록에 변조 내역이 남습니다.
   - 일일 제한·주말 제한·사용 금지 시간대를 바꾸거나 끌 때도 비밀번호가 필요합니다.

4. **일일 사용 제한 (v1.4.0 신규)** ⏱️:
   - "하루 최대 2시간"과 같은 **일일 총량 제한**을 설정할 수 있습니다.
   - 오늘의 누적 사용 시간이 제한에 도달하면 새로운 타이머 시작이 거부되며, 초과 시 자동으로 타이머가 남은 허용 시간에 맞춰 조정됩니다.
   - 대시보드에서 오늘 남은 허용 시간을 실시간으로 확인할 수 있습니다.

5. **작업 관리자 강제 종료 대응 (v1.4.0 신규)** 🛡️:
   - 타이머 상태가 30초마다 파일에 자동 저장되므로, 자녀가 작업 관리자(Task Manager)로 프로세스를 강제 종료해도 **다음 실행 시 타이머가 자동으로 복원**됩니다.
   - 카운트다운/스케줄 타이머의 경우 프로그램이 꺼져 있던 경과 시간까지 정확히 차감합니다.

6. **동작 실행 전 60초 유예 시간 및 화면 잠금 지원 (v1.5.0 신규)** ⚠️:
   - 타이머 만료 시 즉시 실행되지 않고, 설정에 따라 **"60초 후에 시스템 종료/로그오프/화면 잠금이 실행됩니다"** 경고를 표시하며 작업을 저장할 시간을 부여합니다.
   - 화면 잠금 및 로그오프의 경우 부모가 비밀번호로 타이머를 정지하면 예약된 동작이 취소됩니다.

7. **게임 프로세스 프리셋 제공**:
   - 콤보박스를 통해 자주 제한하는 대표 게임(로블록스, 마인크래프트, 리그 오브 레전드 등)을 선택해 이름 입력의 번거로움을 줄였습니다.

8. **게임만 종료 (v1.6.0 신규)** 🎮:
   - 특정 게임 제한 모드에서 시간이 다 되면 PC를 끄는 대신 **게임만 강제 종료**할 수 있습니다.
   - 그날은 게임을 다시 켜도 3초 안에 다시 종료되며, 비밀번호로 중지하거나 날짜가 바뀌면 해제됩니다. 프로그램을 재시작하거나 재부팅해도 유지됩니다.

9. **주말 일일 제한 별도 설정 (v1.7.0 신규)** 📅:
   - "주말(토·일) 따로 설정"을 켜면 토·일요일에는 평일과 다른 일일 제한 시간이 적용됩니다.

10. **사용 금지 시간대 (v1.8.0 신규)** 🌙:
    - 예: 21:00 ~ 07:00처럼 PC 사용을 막을 시간대를 지정합니다. 자정을 넘기는 시간대도 지원하며, 타이머를 켜지 않아도 적용됩니다.
    - 시작 10분·5분·1분 전에 경고하고, 시작되면 실행 중인 타이머를 멈춘 뒤 60초 유예 후 선택한 동작을 실행합니다("게임만 종료"는 화면 잠금으로 대체).
    - 금지 시간대에는 타이머 시작이 거부되며, 부모가 비밀번호로 중지하면 해당 시간대가 끝날 때까지 해제됩니다.
    - 금지 시간대가 켜져 있으면 창을 닫아도 트레이에서 계속 실행되며, 트레이에서 프로그램을 종료하려면 비밀번호가 필요합니다.

11. **간결해진 화면과 새 아이콘 (v1.9.0 신규)** 🎨:
    - 메인 화면에는 오늘 상태 요약(남은 허용 시간·금지 시간대), 모드 선택, 종료 동작, 시작 버튼만 남겨 스크롤 없이 한눈에 보입니다.
    - 일일·주말 제한, 사용 금지 시간대, 언어·테마, 비밀번호 변경은 ⚙ **설정** 화면으로 옮겼습니다. 제한 시간은 "저장"을 누르고 비밀번호를 확인하면 저장됩니다.
    - 실행 파일, 창, 트레이에 새 시계 아이콘을 적용했습니다.

12. **성능 및 보안 최적화**:
   - **AppData 보안 격리**: 비밀번호 및 설정 정보 파일을 사용자 숨김 폴더(`%LOCALAPPDATA%\TimeParents`)로 이동 및 자동 마이그레이션하여 자녀의 고의 파일 삭제를 방지합니다.
   - **Windows API 직접 호출**: 매초 `tasklist.exe`를 실행하는 대신 Windows 커널 API를 직접 호출하여 감지하므로 CPU 및 디스크 사용량이 사실상 **0%**에 가깝습니다.

## 🛠️ 실행 및 빌드 방법 (How to Run & Build)

### 의존성 설치
본 프로그램은 현대적인 UI와 백그라운드 트레이 구동을 위해 다음 라이브러리를 사용합니다.
```bash
pip install -r requirements.txt
```

### 파이썬으로 실행
```bash
python main.py
```

### 실행 파일(EXE) 빌드
`build_exe.bat` 파일을 더블 클릭하거나 콘솔에서 다음 명령어를 실행합니다. 빌드 설정은 `TimeParents.spec`에서 관리합니다.
```bash
pyinstaller --noconfirm TimeParents.spec
```
빌드가 완료되면 `dist/TimeParents.exe` 경로에 실행 파일이 생성됩니다.

### 아이콘 다시 만들기
`assets/icon.ico`와 `assets/icon.png`는 다음 스크립트로 생성합니다.
```bash
python tools/make_icon.py
```

### 테스트 실행
```bash
python -m unittest discover -s tests
```

## 🔑 비밀번호 분실 시 재설정 방법 (How to Reset Lost Password)

비밀번호는 보안을 위해 해시로 저장되어 직접 복구할 수 없습니다. 또한 파일과 레지스트리 두 곳에 저장되어 있어 **두 곳을 모두 지워야** 초기화됩니다. (파일만 지우면 레지스트리 값으로 자동 복구됩니다.)

1. 작업 표시줄 트레이에서 TimeParents를 종료합니다(작업 관리자로 종료해도 됩니다).
2. 키보드의 **`Windows 키 + R`**을 누르고 **`%LOCALAPPDATA%\TimeParents`**를 입력해 폴더를 엽니다.
3. 해당 폴더 내의 **`password.json`** 파일을 삭제합니다.
4. 명령 프롬프트에서 다음 명령으로 레지스트리 백업 값을 삭제합니다.
   ```bash
   reg delete "HKCU\Software\TimeParents" /v PasswordHash /f
   ```
5. 프로그램을 재실행하면 초기 비밀번호 설정 화면이 다시 나타납니다.

## 📝 버전 기록 (Version History)

기능이 추가될 때마다 부 버전(1.x.0)을, 버그만 수정할 때는 수 버전(1.x.y)을 올립니다. 버전은 `main.py`의 `VERSION` 한 곳에서 관리하며, 이 문서 제목의 버전과 일치하는지 테스트로 확인합니다.

- **v1.9.0**: 메인 화면 간소화와 설정 화면 분리, 새 앱 아이콘

- **v1.6.0**: 특정 게임 제한의 "게임만 종료" 동작과 당일 게임 차단
- **v1.5.0**: 동작 실행 전 60초 유예 시간, 화면 잠금 지원
- **v1.4.0**: 일일 사용 제한, 강제 종료 후 타이머 복원
