# TimeParents 자녀 계정 모드

Windows 10/11 Pro, Education, Enterprise의 64비트 PC에서 사용합니다. 부모 계정은 관리자, 자녀 계정은 아이별 표준 사용자로 준비하세요. 아이가 아는 부모 계정의 비밀번호와 PIN도 변경하세요.

## 처음 설정

1. ZIP 전체를 한 폴더에 풉니다. 부모 계정에서 새 **TimeParents.exe**를 실행하세요. 기존 버전이 열려 있다면 타이머를 확인한 뒤 트레이 메뉴에서 종료하세요.
2. 자녀 Windows 계정으로 한 번 로그인해 프로필을 만든 뒤 **로그아웃**합니다.
3. 부모 계정에서 **설정 → 자녀 계정 및 사용 기록**을 엽니다. 기존 TimeParents 부모 비밀번호와 Windows 관리자 승인을 거칩니다. 처음에는 Windows 서비스 설치 여부를 묻습니다.
4. **자녀 계정 등록**에 표준 계정의 Windows 사용자 이름을 입력하세요. 초기 한도는 아이마다 평일·주말 각 60분입니다. 아이를 선택하고 원하는 시간을 입력한 뒤 **한도 저장**을 누릅니다.
5. 야간에 사용을 막으려면 **공통 금지 시간**을 켜고 시각을 저장하세요. 저녁 9시부터 다음 날 오전 7시까지처럼 자정을 넘기는 설정도 지원합니다.
6. 아이가 로그인하면 **30분, 1시간, 1시간 5분, 1시간 30분**을 고르거나 원하는 분을 직접 입력합니다. 남은 한도와 금지 시각 중 먼저 도달하는 시점까지만 사용할 수 있습니다.

## 사용과 기록

- 바탕화면의 시간 창에서 **사용 끝내기**를 누르면 그때까지 쓴 시간만 차감됩니다. 시간이 끝나면 선택 화면으로 돌아갑니다. 같은 Windows 세션에 열려 있던 작업은 다음 이용 시 이어갈 수 있습니다. 로그아웃 전에는 작업을 저장하세요.
- 사용 끝내기, 잠금, 사용자 전환, 로그아웃, 절전 후 같은 날 돌아오면 남은 시간을 먼저 이어 씁니다. 예를 들어 30분 중 12분을 쓰면 18분부터 이어집니다. 예상치 못한 종료에서는 마지막 저장 시각까지 계산하므로 수 초의 차이가 생길 수 있습니다.
- 부모 화면에서 아이를 고르면 오늘의 사용·잔여 시간과 로그인, 이용 시작, 종료, 선택 시간, 계산된 사용 시간, 종료 사유가 보입니다. **기록 새로 고침**으로 진행 중인 이용도 확인할 수 있습니다. 선택하지 않고 로그아웃하면 이용 시간은 0입니다. **오늘 10분 추가**는 해당 자녀의 오늘 한도에만 적용됩니다.
- 기록은 이 PC의 관리자와 서비스가 접근하는 Windows 레지스트리에 저장합니다. 부모 화면에서 최근 90일 기록을 확인할 수 있습니다. Windows 계정을 기준으로 집계하므로 아이마다 자기 계정으로 로그인하세요.

## 적용 방식과 복구

[Windows 사용자 지정 인터페이스 정책](https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-admx-winlogon#customshell)으로 등록한 계정의 첫 화면을 시간 선택기로 설정합니다. 이용을 시작하기 전에는 별도의 Windows 데스크톱을 표시합니다. 선택기는 자녀 권한으로 실행되며 Windows 서비스가 한도와 기록을 관리합니다. 등록한 표준 계정에서 일반적인 바탕화면 사용을 관리하는 기능이며, 기관용 키오스크 수준의 앱 실행 제한은 별도 Windows 정책이 필요합니다.

- **일반 해제**는 부모 관리자 화면에서 아이를 선택하고 **등록 해제**를 누르세요. 다음 로그인부터 Windows 바탕화면으로 시작합니다. 기존 기록은 부모가 계속 확인할 수 있습니다.
- **서비스나 선택기에 문제가 생기면** 자녀 화면에서 로그아웃하거나 Windows 보안 화면에서 사용자를 전환해 부모 계정으로 로그인하세요. 선택 화면을 복구할 수 없을 때 서비스가 해당 자녀 세션을 로그아웃할 수 있습니다.
- **부모 앱 없이 복구**할 때는 관리자 계정의 64비트 Windows PowerShell에서 아래 명령을 실행합니다. 실제 자녀 계정 이름을 입력하세요. 첫 번째 명령은 해당 계정에 TimeParents가 지정한 셸을 해제합니다. 모든 자녀를 해제한 뒤 두 번째 명령으로 서비스를 제거할 수 있습니다. 두 작업 모두 계정과 기록을 보존합니다.

~~~powershell
& "$env:ProgramFiles\TimeParents Family\Setup.ps1" -Action Remove -Account '자녀계정'
& "$env:ProgramFiles\TimeParents Family\Setup.ps1" -Action Uninstall
~~~

## 개발 및 검증

기존 Python 빌드 명령으로 Windows에 포함된 64비트 .NET Framework 컴파일러를 호출해 도우미도 빌드합니다. 배포할 때는 **TimeParents.exe** 옆에 **family** 폴더를 함께 두세요. 소스에서 실행할 때는 프로젝트에서 먼저 **python tools/build_family.py**를 실행합니다.

자동 테스트는 가상 시각과 독립 Windows 파이프로 계정별 차감 및 통신을 검사합니다. 배포 전에는 별도의 표준 계정에서 첫 로그인, 시간 선택, 조기 종료, 잠금·절전, 재로그인, 등록 해제까지 확인하세요.
