# Windows 계정 하나로 가족 프로필 사용하기

## 처음 한 번 설정하기

1. 이전 버전이 실행 중이면 타임페어런츠 트레이 메뉴에서 종료합니다. 사용할 폴더에 새 버전을 두고 평소 가족이 쓰는 Windows 계정에서 TimeParents.exe를 실행합니다.
2. 메인 화면이나 설정에서 **가족 프로필 · Windows 계정 하나로 사용**을 선택합니다. 기존 TimeParents 부모 비밀번호를 입력합니다. 처음 설치했다면 앱의 첫 실행 화면에서 부모 비밀번호를 정합니다.
3. **새 자녀**를 눌러 아이 이름, 숫자 PIN 4~12자리, 평일·주말 하루 한도(분)를 입력하고 **프로필 저장**을 누릅니다. 형제자매도 같은 방법으로 추가합니다. 각 아이가 자기 기록을 구분할 수 있도록 서로 다른 PIN을 정하세요.
4. **공유 로그인 시작**을 누릅니다. 지금 가족 선택 화면이 열리고, 이후에는 같은 Windows 계정에 로그인하면 TimeParents가 자동으로 시작합니다. Windows 시작 앱에서 TimeParents가 켜져 있어야 합니다. 실행 파일을 옮기면 새 위치에서 한 번 실행하세요.

## 매일 사용하기

- 아이는 자기 이름을 선택하고 PIN을 입력한 뒤 **30분, 1시간, 1시간 5분, 1시간 30분**을 고르거나 원하는 분을 직접 입력합니다. 남은 한도나 공통 금지 시간까지 쓸 수 있는 시간이 더 짧으면 그만큼만 이용할 수 있습니다.
- 30분을 골라 12분 쓰고 끝내면 같은 날에는 **남은 18분 이어쓰기**로 다시 시작합니다. 쉬는 동안에는 차감되지 않습니다. 남은 시간을 다 쓰면 하루 한도 안에서 새 시간을 고를 수 있습니다.
- **사용 끝내기**를 누르거나 시간이 만료되면 가족 로그인 화면으로 돌아갑니다. 일찍 끝내면 실제로 이용한 시간만 차감됩니다. Windows 잠금이나 절전 후에도 다시 가족을 선택합니다.
- 부모는 **부모 로그인**에서 기존 앱 비밀번호로 들어갑니다. **가족 프로필 및 사용 기록**에서 자녀를 고르면 최근 90일의 앱 로그인 시각, 사용 시작과 종료, 선택한 시간, 실제 사용 시간, 종료 사유를 볼 수 있습니다. 같은 화면에서 평일·주말 한도, 오늘만 10분 추가, 가족 공통 금지 시간, PIN 변경도 관리합니다.
- 부모가 자리를 비울 때는 **사용자 전환**을 누르거나 **Win+L**로 Windows를 잠그세요. 가족 프로필을 끄려면 부모로 로그인한 뒤 관리 화면에서 **공유 로그인 끄기**를 누릅니다.

## 기록 범위

가족 기록은 이 PC의 공유 Windows 사용자 폴더에 저장됩니다. Windows 로그인 후 시작 앱이 열릴 때까지 걸리는 시간은 PC마다 다릅니다. 아이의 신원은 앱에서 입력한 PIN으로 구분하므로, 다른 사람의 PIN을 사용하면 해당 프로필에 기록됩니다. 같은 Windows 계정 권한으로 앱을 강제 종료하거나 자동 시작을 끄면 그동안의 사용자를 식별하거나 사용을 제한할 수 없습니다.
